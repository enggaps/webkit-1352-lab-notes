# Security & disclosure policy

This repository is security research conducted for defensive purposes on hardware
and networks under my own control. It is published to document methodology and
reproducible observations, not to distribute working exploits.

## Responsible disclosure

If any work here identifies a new security issue with clear vendor impact, I will:

1. Report it privately to the vendor's official security channel first
   (for PlayStation: https://hackerone.com/playstation).
2. Withhold operational exploit code, offsets, and payloads from this public
   repository until the vendor has had a reasonable opportunity to remediate.
3. Publish only the level of technical detail that has been coordinated.

## What is never published here

- Working exploit chains, payloads, kernel patches, or persistence methods.
- Live addresses, raw memory captures, or firmware dumps.
- Console identifiers, private network details, or account data.
- Testing against systems I do not own or control.

## Reporting to me

If you believe something in this repository should not be public, or you have
information relevant to coordinated disclosure, open an issue with no sensitive
detail and I will follow up privately.
